## 快速开始

```bash
cd zc-system
npm install --registry=https://registry.npmmirror.com   # 首次
npm run dev        # 开发：http://localhost:5173
npm run build      # 构建 → dist/
npm run preview    # 预览构建产物（本机演示用）
npm run smoke      # 逻辑冒烟测试（17 项断言，无需浏览器）
```

**本机演示已开**：http://localhost:4655（vite preview，若失效重新运行 `npm run preview`）

## 运行模式

- **单机模式（当前默认）**：数据存浏览器 localStorage。**首次打开自动播种 68 家客户（仅一次）；清空数据后不再自动播种**，需要时在设置页点「初始化 68 家客户」。多人不共享数据，务必每周导出备份。
- **云端模式（多用户）**：`src/config.js` 填入 CloudBase 环境 ID + 开启用户名密码登录。代码已就绪（db.js 双适配），部署时联系 ZCODE。

## 数据清空与恢复

- **设置 → 危险操作 → 清空全部数据**：输入「清空」二次确认，删除本浏览器的客户/任务/税金/财务/阿米巴全部数据（保留团队与参数）。适合系统交付前清掉测试数据、或换月重置。
- 注意单机模式数据按浏览器隔离：**每个用过的浏览器都要各自清一次**。
- 恢复 68 家演示数据：设置页「初始化 68 家客户」；恢复业务数据：导入之前导出的 JSON 备份。

## 每月客户名单更新（模板导入）

- 模板：`ZC-客户信息导入模板.xlsx`（列序对齐股改明细表 A:M，旧表整块复制粘到 B5 即可；表内自带公式：月记账费=年÷12、剩余月份/剩余金额按当天实时算、序号自动编号）
- 入口：设置 → 「📋 客户名单模板导入」→ 选择 Excel → 预览（新增/更新/跳过计数 + 本期营业额截止日 + 告警）→ 确认导入
- 规则：按 纳税人识别号 → 公司名称 匹配（兼容括号注记/简称模糊匹配）；命中更新资料、未命中自动建档（序号接续）；示例/合计/空行自动剔除；同文件重复客户取最后一行并提示
- 分级口径：按「客户营业额（截至月末，元）」快照**每月导入时判一次** S1/S2/S3（>100万 S3；>0 S2；空或 0 S1），平时不动态变；客户页「手动锁档」的客户不重划
- 随档案留存的扩展字段：合同金额 contractAmount、佣金 commission、收费周期 payCycle（暂无页面展示，数据不丢）
